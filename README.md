# Plato Scroll — the library, one file per book

Every work in [Plato Scroll](https://plato-scroll.com) as a typeset PDF and an EPUB, one file each:

- `pdfs/<Author>/<Title>.pdf` — half-letter pages, Gentium Plus, footnotes, speaker labels and page/Stephanus references, a title page with a QR link back to the reader.
- `epubs/<Author>/<Title>.epub` — the same text chaptered for e-readers.
- Files ending in `-Greek`, `-Latin`, `-Sanskrit` or `-Spanish` are the companion editions of the same work.

The reader's ⤓ Download button links straight to the two files for the book that is open. The whole set is also one zip on the
[releases page](https://github.com/mjcizek17/plato-scroll/releases/latest).

The translations are public domain or openly licensed; see [Texts & Licences](https://plato-scroll.com/attribution.html).
